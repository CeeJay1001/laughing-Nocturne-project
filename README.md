# Nocturne Booksellers

A dark-academia bookstore showcase created as a personal front-end project.

## My Role

I created the visual identity, logo, book-card artwork, writing, and website implementation. This project demonstrates graphic design, content design, HTML, CSS, JavaScript, responsive layout, and interaction design.

## Features

- Responsive bookstore layout
- Featured Books, Staff Picks, and New Arrivals sections
- Search and genre filtering
- Book detail modal
- Borrow and unborrow interactions
- Borrowed list saved in the browser with `localStorage`
- Custom typography, hover states, loading animation, shadows, and favicon

## Run Locally

Open `TEST DRIVE.html` in a browser. No build tools or dependencies are required.
